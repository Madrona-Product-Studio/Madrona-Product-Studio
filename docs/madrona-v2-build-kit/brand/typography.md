# Typography

## Primary typeface

**Inter** is the default for headings, body copy, navigation, controls, labels, and product demonstrations.

- Hero H1: 64–72px desktop, 42–48px mobile, weight 600, line-height 0.98–1.05.
- Section H2: 40–48px desktop, 32–36px mobile, weight 600.
- H3: 24–28px, weight 600.
- Lead: 18–20px, line-height 1.5–1.6.
- Body: 16–18px, line-height 1.55–1.65.
- UI and labels: 12–15px. Avoid tiny all-caps labels as the main hierarchy.

## Editorial accent

**Fraunces** is an accent, not the default page-title typeface. Use it sparingly for selected project moments, quotations, and expressive statements.

## Operational mono

Use the existing system monospace stack for order data, agent steps, sources, timestamps, and structured outputs. Keep it small but readable.

## Heading rule

A visitor reading only the headings should still understand the page. Concrete payload first, expressive language second.
