# Visual reference hierarchy

## 1. `homepage-north-star.png`

This is the primary visual reference. Match closely:

- overall visual density and section rhythm
- split hero composition
- cream, forest, bark-orange, and ink balance
- organic landscape crop
- compact audience strip
- three service artifacts
- Berry Good end-to-end feature
- products-we-build section
- founder-led operating-model section
- capability sequence
- split CTA and dark footer

Do not copy literally:

- invented metrics or outcomes
- inaccurate project screens
- placeholder people as real team members
- unapproved navigation destinations
- fake client language

## 2. `madrona-applications-01.png` and `madrona-applications-02.png`

Use for logo scale, spacing, dark/light applications, print-like restraint, and the forest/orange balance.

## 3. `berry-good-brand-guide.png`

Use to understand how branding should be shown as a functioning system: identity, palette, type, voice, photography, usage, and application. Do not import Berry Good's palette into the Madrona shell.

## 4. Generated product and photography placeholders

Use them to establish spacing, cropping, and visual direction. Replace product mockups with repository-accurate assets as soon as practical. Replace people and place photography before production launch.
