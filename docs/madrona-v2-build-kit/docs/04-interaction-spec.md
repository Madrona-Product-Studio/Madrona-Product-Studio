# Interaction specification

## Approved mechanisms

- Service selector
- Workbench
- Scenario switcher
- Before-and-after flow
- Run example
- Reveal the thinking
- Build receipt

## Principles

- Default state communicates value.
- Interaction reveals something a screenshot cannot.
- Controls use familiar labels.
- Essential information is not hover-only.
- Motion is fast and restrained, generally 150–300ms.
- No fake loading or staged thinking delays.
- Every sequence can be reset or reversed.
- Reduced-motion users receive immediate state changes.

## Berry Good order agent

Do not build a generic chat window. Present a business input, the useful work performed, a structured output, and a human decision state.

## Mobile

Replace wide side-by-side flows with a clear sequence. Preserve the relationship between before and after, input and output, and route options without requiring horizontal zoom.
