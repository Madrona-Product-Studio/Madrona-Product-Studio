# V2 design system

## Visual target

Use `references/homepage-north-star.png` as the direct north star. The site should feel warm, contemporary, and senior, with more visual grouping and artifact-led storytelling than the current site.

## Logo

Use assets from `brand/madrona/web/`. Preserve originals in `brand/madrona/source/`. The logo colors are authoritative.

## Color roles

- Paper: primary background
- Surface: workbenches and artifacts
- Shell and sand: quiet content grouping
- Forest: brand foundation, large dark surfaces, footer, selected buttons
- Bark: emphasis and primary action
- Ink: text

Orange and forest must not become competing CTA systems. Choose one primary action treatment per surface.

## Type

Inter is the default heading and interface face. Fraunces is a selective editorial accent. Use the operational mono stack for structured data and agent output.

## Layout

- Editorial width: 720px
- Standard width: approximately 1180px
- Wide artifact width: approximately 1360px
- Desktop gutters: 48–64px
- Tablet gutters: 32px
- Mobile gutters: 20px
- Major section spacing: 112–144px desktop, 72–96px mobile

## Surfaces

Tonal containers are allowed and encouraged when they establish a meaningful unit. Avoid generic card grids, excessive borders, and repeated drop shadows. Reserve shadows for physical-looking artifacts or floating interface layers.

## Organic forms

Use the supplied masks sparingly for major images and selected brand moments. Do not place every image in a circle.
