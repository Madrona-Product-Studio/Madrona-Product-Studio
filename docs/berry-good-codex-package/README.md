# Berry Good Codex Package

This package contains the implementation specification, source logo files, existing brand documentation, and visual reference crops for the five-view Berry Good case-study section.

Start with:

1. `berry-good-case-study-tabs-spec.md`
2. `berry-good-brand-guide.md`
3. `berry-good-site-implementation-brief.md`

The files in `assets/reference/` are directional mockups. They are not production-ready UI screenshots and should not be embedded as the final implementation.

The files in `assets/brand/` are the supplied SVG mark assets.
