# Madrona Product Studio logo package

This package contains production-ready logo assets for the approved final direction.

## Recommended web usage

### Header / navigation
- Use `madrona_primary_horizontal_logo.svg` on light backgrounds.
- Use `madrona_primary_horizontal_logo_reversed.svg` on dark forest-green backgrounds.

### Footer / dark sections
- Use `madrona_primary_horizontal_logo_reversed.svg`.

### Favicon / social avatar / app icon
- Use `madrona_standalone_mark.svg` or `madrona_app_icon_light.svg`.
- For dark circular treatments, use `madrona_app_icon_dark.svg`.

### Small or constrained spaces
- Use `madrona_standalone_mark.svg`.

## Color values
- Forest Green: `#1F3B33`
- Terracotta: `#C86A3D`
- Charcoal: `#222222`
- Mist Gray: `#A8A8A8`
- Off White: `#F7F4EF`

## Minimum recommendations
- Primary horizontal logo: at least 120 px wide in digital contexts.
- Standalone mark: at least 32 px wide for favicon-like use, 48 px preferred.
- Keep clear space around the logo equal to roughly the height of the lowercase “m”.

## Font recommendation
The logo files use a modern rounded sans-serif stack for portability:
`Poppins, Inter, Lato, Arial, sans-serif`

If your site already loads Poppins, it will most closely match the approved direction.
